# Unirse a TestFlight

- Ayuda a mejorar mis aplicaciones informando de cualquier error o característica que te gustaría ver.
- Utilice el botón de la aplicación para solicitar una invitación. No envíes un correo electrónico vacío. Escribe una breve explicación de por qué quieres unirte al grupo de prueba.
- Debe proporcionar una dirección de correo electrónico válida para recibir la invitación.

## Cosas a tener en cuenta

- El acceso a TestFlight es limitado. No todos los usuarios verán la opción de solicitar una invitación.
- Todas las compras dentro de la aplicación son gratuitas en las versiones beta.
- Hay hasta 10.000 espacios disponibles por aplicación.
- Para seguir siendo parte del programa beta, debe proporcionar comentarios y usar la aplicación regularmente. De lo contrario, serás eliminado de la lista.
- Para proporcionar comentarios, use el botón en la aplicación TestFlight. Es la única manera para mí de hacer un seguimiento de qué usuarios proporcionan comentarios y cuáles no.
- Las versiones beta caducan después de un cierto tiempo. Una vez que esto suceda, la aplicación ya no se abrirá ni funcionará.
- Las versiones beta pueden contener errores y características inéditas. También pueden causar la pérdida de datos.
